# Local Studio App — Hướng Dẫn Sử Dụng

## Khởi Chạy Nhanh
- Nhấp đúp file **`CHAY-APP.bat`** tại thư mục `C:\Users\Ngoc Hieu\Desktop\YT stuff\local_tool\`.
- Ứng dụng sẽ tự động khởi chạy server ngầm tại `http://127.0.0.1:8770/` và mở giao diện ứng dụng.

## Cấu Hình API Key Cá Nhân
1. Mở file **`config_keys.json`** trong thư mục `local_tool`.
2. Dán API Key cá nhân của bạn (Gemini, Groq, DeepSeek...) vào mục `"key"`.
3. Hoặc nhập/quản lý trực tiếp trên giao diện Dashboard mục **Cấu hình AI Key**.

## Các Thư Mục Lưu Trữ
- Mã nguồn ứng dụng: `local_tool/src/`
- Môi trường Python: `local_tool/.venv/`
- Video đã cào & dữ liệu: `MediaCrawler/data/`
- Video đã render thành phẩm: `processed_videos/`
